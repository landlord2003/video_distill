## 3. 模块设计（扩展 crawl4ai-app，不另建项目）

**`app.py` 改动**
- 新增 `POST /api/video`：`{mode: "drag"|"url"|"auto", payload}` → 调用 video_pipeline
- 复用 `/api/history`、`/api/crawls/<id>`、`/api/crawls/<id>/download`、`DELETE`
- crawls 表加 `type` 字段（web/video）区分；video 记录同样进历史与可搜索

**新增 `video_pipeline.py`（核心）**
- `download(url)` → 本地文件（ffmpeg 合并 m3u8 分片）
- `extract_audio(video)` → wav（ffmpeg，-vn -acodec pcm_s16le）
- `extract_frames(video, n=4)` → 关键帧 png 列表（ffmpeg -vf fps 或均匀抽）
- `transcribe(wav)` → 全文文本（faster-whisper）
- `describe_frames(frames)` → 各帧文字描述（qwen3-vl:8b）
- `summarize(transcript, frame_desc)` → 结构化 JSON（qwen3:14b：摘要/章节/要点/标签/来源/时长）
- `build_markdown(...)` → 最终 .md
- `save_to_vault(md, meta)` → 写 `Claw/07-视频号整理/<标题>.md`
- `save_to_ima(md, meta)` → IMA MCP 直写（待配置，未配置则跳过并留待导入副本）

**`index.html` 改动**
- 新增"视频号"标签页：拖拽区 / 直链输入 / watch 状态 / 历史列表（复用现有样式）

**`watch/` 监控（P1）**

## 4. 数据流（P0 单次处理）

1. 用户拖入 `.mp4` 或贴直链 → `POST /api/video`
2. (url 模式) ffmpeg 下载合并到 `tmp/`
3. ffmpeg 抽音频 wav + 抽 4 张关键帧 png
4. faster-whisper 转写全文（带时间戳）
5. qwen3-vl:8b 描述每张关键帧
6. qwen3:14b 综合「转写+帧描述」生成结构化 JSON（摘要/章节/要点/标签/来源）
7. build_markdown → `Claw/07-视频号整理/<标题>.md`
8. (IMA 配置后) save_to_ima
9. 写 crawls 历史（type=video），前端可查/下载/删除

## 8.5 获取实操（各平台真实可行路径，2026-09-07 实测）

### 抖音（含抖音视频号）：复制链接 + yt-dlp（已装，最推荐）
- 抖音 App/网页 → 视频"分享" → "复制链接" → 得到 `v.douyin.com/xxxx`
- 链接贴入工具（/api/video 的 douyin 模式）→ yt-dlp 本地下载 → 自动进整理流水线
- 本地化、开源、合规、零灰产；获取需联网（访问抖音服务器，不可避免），整理全本地
- 无水印高清需你导出抖音 cookie（进阶，涉及平台规则，按需）

### 微信视频号：手动 / 抓包（PC 缓存自动收已实测不可行）
- 实测结论：PC 微信 `xwechat_files\...\msg\video` 仅缓存 `*_thumb.jpg` 缩略图，不落完整视频文件；`.dat` 缓存为图片加密、不含视频。故"监控 PC 缓存自动收视频号"走不通，已删除该路径。
- 方法1（最稳，立即可用）：手机微信视频号 → "..." → "保存到手机相册" → 视频传到电脑 → 拖入工具（P0 拖拽）
- 方法2（半自动，需你配合）：Charles/mitmproxy 拦视频号请求拿直链 → 贴工具 ffmpeg 下载（P0 直链）；需绕过微信 SSL Pinning
- 方法3（手机端）：安卓微信视频号缓存目录导出（需手机文件管理/Root）

### 明确不做
- 不抓包逆向微信协议、不装安卓 Xposed 模块（灰产/封号风险）
