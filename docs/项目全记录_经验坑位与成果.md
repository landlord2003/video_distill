## 一、项目是什么

**多平台内容采集 → 本地蒸馏 → Markdown 入 Obsidian（E:\Workbuddy\Claw）** 的一体化本地工具：

```
采集流水线（8 源统一）→ 下载/抓取 → 转写（faster-whisper）/正文提取
  → 摘要蒸馏（qwen3:14b 分段提取式）→ Obsidian 笔记（Claw/07·08 等目录）
  → 记录中心（分类/来源/作者三维度管理）
```

- 全本地零 API 费：Ollama qwen3:14b（蒸馏）/ qwen3-vl:8b（OCR）/ faster-whisper small（转写）
- 技术栈：Python venv + ThreadingHTTPServer + Playwright(msedge) + yt-dlp + ffmpeg
- UI 三页签：🚚 采集流水线 / 🎙 TTS·播放器 / 📚 记录中心（+ ⚡ 技能包蒸馏功能卡）
- 数据库：crawls.db（videos + articles + tts + dim_pool 表），大产物不入 git

## 四、平台采集知识库（核心资产）

### 4.1 抖音（最深）
- **下载五级链**（video_downloader.download_douyin）：
  0. 免 cookie 分享页直链（iesdouyin `_ROUTER_DATA` + iPhone UA，借鉴 chubbyskills）
  1. cookies.txt（项目内 / VIDEO_COOKIES）+ UA + Referer
  2. 浏览器实时 cookie ×4（chrome/edge/chromium/brave）
  3. playwright 无头拦截 `aweme/v1/web/aweme/detail`（**msToken 前端实时生成，任何静态 cookie 方案必败，页内拦截是正解**）
  4. **CDP 真实浏览器兜底**（douyin_cdp.py，10-24 新增）
- **精确判决直通**：filter_detail（core_dep=作品不存在 / status_self_see / status_review）原样上抛，绝不追加误导性 cookie 建议
- **签名重放突破**：服务端对改 cursor 后的旧 X-Bogus **不校验**（至少列表接口）→ 页面上下文 fetch 循环翻页（cursor=max_cursor 链，1.2~2s/页限速）。合集与主页采集通用
- **双合集体系**：mix/aweme/（普通）与 series/aweme/（系列类）响应结构相同，拦截词两者都收
- **付费解锁短剧合集**（7393662529248954380 定性）：mix/aweme 返回完整结构但 `aweme_list` 仅免费部分（1 条）+`has_more=0`+`ad_charge_passive_unlock_config`；**新设备指纹只发免费部分，与 cookie 无关**。修法=在调试 Edge（cdp_profile）里登录抖音建立设备信任
- **风控渐进式降级**：①列表接口 200+status_code=0+空列表（不是失败，是降级形态）→②无头会话高频探测后 detail 也停摆（页面不发请求）→③裸 curl 被 ArgusSecurityPlugin 403。**发现列表空就停手换环境，别加测**；重导 cookie 无效（指纹级）
- **原声歌名**：matched_song=null 时数据层本无歌名/歌词，标题=文案+「(号主 原声)」，歌词靠转写喂给用户人工定名——不做假功能
- **文件名红线**：desc 常带话题标签换行 → 必须先 `re.sub(r'\s+',' ')` 压空白再替换非法字符 + `strip(' .')`，否则 ffmpeg 打不开输出文件
- **链接全形态**：video/note/slides/modal_id/纯数字/短链 → `resolve_aweme_id()` 统一收口

### 4.2 YouTube
- 2026 年可靠三件套：**nightly yt-dlp.exe（项目内固定）+ cookies（yt_cookies.txt）+ node JS 运行时**（--js-runtimes）
- 必须 `--ffmpeg-location`：否则静默跳过 bestvideo+bestaudio 合并 → 无音轨 fNNN.mp4 → 转写 tuple index out of range
- `_pick` 优先合并成品、清理 split 中间产物；--cookies-from-browser 在 Windows Chromium 127+ 因 DPAPI/App-Bound 加密基本失效，**插件手动导出是唯一可靠路径**

### 4.3 Twitter/X
- 单条免 cookie 三通道：fxtwitter（实测主用）→ vxtwitter → syndication
- **X 原生长文（Article）全文就在 fxtwitter 响应里**（draft-js blocks），不需要 GraphQL
- 账号清单：twikit + 深度兜底补丁（X 频繁瘦身边响应：legacy 硬取键全给默认值、ondemand.s chunk 名与哈希拆两张映射表重建 URL）；queryId 运行时从 bundle 提取不硬编码
- guest user_timeline 已被官方关停（404）；syndication timeline 常年 429

### 4.4 其他平台
- **公众号**：bs4 全文提取（chubbyskills 脚本 vendor 进来），稳定
- **小红书**：需 XHS_COOKIE；图片本地化到 vault（CDN 外链带时效 token 必过期）；图片型笔记正文<120 字自动 OCR 兜底
- **知乎专栏**：渲染后 403 是误报，SSR HTML 内嵌 js-initialData 含全文（entities 在 initialState.entities 下）
- **VOA（iyuba）**：play.jsp #senAll 逐句双语（**单引号属性**）；音频 staticvip.iyuba.cn 直链；CV 视频栏目与音频同 id 空间有 mp4 直链；/media/ 路由必须实现 **Range 206**（视频拖进度必需）
- **B站**：yt-dlp 原生，bilibili_cookies.txt 可选
- **通用网页**：轻量 urllib+ChromeUA；**弃用 crawl4ai/chromium 做外链跟进**（AsyncWebCrawler 在 Windows 偶发挂起卡死 15min+）
- **微信视频号**：PC 缓存仅缩略图（实测），自动采集不可行；路径=手机保存→传输→本地上传

## 五、工程红线（写代码必须遵守）

1. **文件名清洗**：压空白→替换非法字符→strip(' .')（见 4.1）
2. **子进程解码**：所有 `capture_output=True, text=True` 必须显式 `encoding="utf-8", errors="replace"`——父进程读子进程输出按 locale GBK 解码，与 sys.stdout.reconfigure 无关
3. **无窗口承载必须 stdio UTF-8**：app.py 启动 `sys.stdout/stderr.reconfigure(encoding="utf-8", errors="replace")`——pythonw+日志重定向下 print 任何非 GBK 字符（如 ✓ U+2713）会炸掉整条兜底链
4. **子进程弹窗**：app.py 入口给 subprocess 全局打 CREATE_NO_WINDOW 补丁（pythonw 下 yt-dlp/ffmpeg/node 各自弹控制台）
5. **子进程必带**：`timeout=` + `stdin=DEVNULL`（ffmpeg 抽帧 PIPE 继承挂死案例）
6. **单实例**：启动前 connect_ex 探测端口 + NoReuseServer（allow_reuse_address=False）——SO_REUSEADDR 允许多进程重复绑 8788，多实例是大量"诡异旧代码"报错的根源
7. **whisper**：默认 CPU（WHISPER_DEVICE=cpu）、全局单例、600s 看门狗线程——"零 CPU+零网络+无子进程的挂死"是在等 GPU/CUDA 初始化，except 抓不住
8. **批量逐条入库**：下载→整理→立即写 DB→单条 try/except 隔离——"全部完成再统一入库"一条卡死全批丢失
9. **摘要质量红线**：qwen3:14b 服从性差（要 JSON 给 Markdown / think 吃光 num_predict / 长输入只总结前半），可靠形态=**分段提取式**（≤2500 字/段×3~5 要点按序合并，think=False）；JSON 失败必走 _rescue_summary（一次回填摘要+要点两节）
10. **md 回写圈定**：删单个区块的范围必须显式圈到下一个**白名单合法章节标题**，不能停在任意 `## `（残片自身可能带 ## 标题）
11. **接口不唯一**：合集 mix/series 按响应结构归并拦截词；OCR 兜底挂全平台后置步骤而非单源分支

## 六、运维坑速查表

| 坑 | 结论 |
|---|---|
| 服务承载 | **explorer.exe 代启 bg_start.vbs**（隐藏 cmd+pythonw，免疫 window-CLOSE）；Bash run_in_background / Start-Process / schtasks / WMI 全会被回收或拦截 |
| 重启验证 | 杀进程→`Get-NetTCPConnection -LocalPort 8788` 确认端口真空→重启→**端到端实测 UI 同款 API**（旧实例也回 health 200） |
| 服务进程身份 | 可能是 pythonw 也可能是 python——按端口找 PID，别按进程名过滤 |
| git commit 假输出 | 5 次以上输出 "nothing to commit" 实际成功；**唯一可信=ls-remote 双端 HEAD**；commit 与 push 分开跑（&& 短路坑） |
| git push 被拒 | 会话沙箱常拦 ~/.ssh 读取——提交安全在本地，待授权或用户手动 push |
| 长流水线 | >10min 的 /api/video 不要 curl 等响应（工具超时杀连接→10054 假象），改后台+轮询 DB/vault |
| "改了没生效" | 排查顺序：实测运行中服务渲染→服务启动时间 vs 提交时间→**用户旧标签页**（高频假象源，Ctrl+F5）；index.html 每请求现读盘，app.py 需重启 |
| Edit 假成功 | Edit 报成功但内容未落盘发生过多次——改完必须 grep 验证目标产物本身 |
| LOLBin 拦截 | Bash 命令含 wscript/explorer/.vbs/PowerShell 等关键词会被安全扫描误拦——拆命令、换措辞或用文件工具 |
| PowerShell 工具 | stdout 偶发全空（连 Write-Output 都空）→ 落盘+Read 兜底；taskkill //PID 参数被 MSYS 改写 |
| JSON POST | bash 拼 Windows 路径 JSON 会炸（\W 非法转义）→ 用 Python urllib 发 |
| venv 突然全灭 | WorkBuddy 升级可能弄残 base Python 的 Lib/——改 venv 的 pyvenv.cfg 指向完整副本（.old.*），不必重建 |
| bat 文件 | 必须 ANSI(GBK)+CRLF、无括号块 goto；Write 工具产出 UTF-8+LF 需二进制转码 |

## 七、验证方法论（沉淀）

- **无头 Playwright+Edge e2e**：`chromium.launch({channel:'msedge'})` 用系统 Edge 免下浏览器；pg.on('pageerror') 收 JS 错误
- **0 高度元素**用 style.display 断言（is_visible 恒 False）；**还原型断言查 DB** 不查页面缓存
- **事件驱动播放器**（timeupdate）必须手动 dispatchEvent；SPA 结构用 page.evaluate 直接调页面内函数，别用 text= 选择器猜
- **对照实验定性**：同一 cookie 同一时刻抓已知好视频 vs 失败视频——区分 cookie 问题/作品问题/风控问题
- **纯函数逻辑**抽出来 node --check + 数据级断言，比整页测试快且准
- **数据级复盘**：UI 报"抓不到"先查 DB/vault 实际状态，多个"失败"实为已成功（12 分钟长流水线被 curl 假象掩盖）
